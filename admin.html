Dashboard ECFS

Internal tool. Paste a Discord chat export (the .html file) below and click Parse. Review the trades, tune the model settings, then copy or download performance.json and commit it to the repo — the public dashboard reads that file on load. Everything runs in your browser; nothing is uploaded.

1 · Paste Discord export

Open the exported .html, select all (Ctrl/Cmd-A), copy, and paste here. Plain message text works too if it keeps the per-message timestamps.

2 · Model settings

Assumptions: every result line counts as one trade outcome (re-entries on the same label count separately); the first number on a result line is the realized points; per-trade size is honored — default 1 ES (\$50/pt), half = 0.5 ES (\$25/pt), 2es = \$100/pt, 5mes = 5×\$5 = \$25/pt. Engine yield = realized \$ ÷ deployed capital; blended = realized \$ ÷ blended capital. Verify outliers in step 3.
